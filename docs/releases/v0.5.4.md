# iCloud Live Photo Picker v0.5.4

本版本解除单次 5000 张对完整图库浏览的限制，并为大图库增加可控的连续加载方式。

当前构建为 **r5**，窗口标题与侧栏显示 `0.5.4 r5`，Windows 文件版本为 `0.5.4.5`。

## 本次更新

- 新增“加载更多”，按界面中的“每次数量”继续追加当前相簿照片。
- 新增“全部加载”，显式读取当前相簿剩余的全部照片。
- 追加加载会保留已经选择的照片、已加载缩略图和当前筛选/排序方式。
- 5000 继续作为普通单次加载的保护上限，但不再限制分批加载或全部加载。
- “全部加载”旁显示列表、缩略图任务和内存压力提示。
- 照片质量和实况视频质量下拉选项统一使用中文显示。
- 修正相簿读取方向：首次加载从最新记录开始，不再把最新照片留到继续加载；移除此前的反向遍历和尾部探测。
- 按资源 ID 去重，实际读取到列表末尾才标记全部加载完成，计数接口只作为参考。
- 修复第一行缩略图任务可能因页面布局切换而遗漏的问题。
- 图库空状态的“加载 iCloud 照片”等入口改为原生 Qt 按钮，具有悬停、按下反馈和手型光标，也可使用键盘操作。

## 首次运行提示

当前文件没有商业代码签名，Windows SmartScreen 可能显示“未知发布者”。请确认文件来自上面的项目网盘链接，并核对发布时公布的 SHA-256 后再运行。

使用“全部加载”处理大型图库时，程序需要保存更多照片条目并调度更多可见缩略图。建议先使用普通加载或“加载更多”，确有需要时再加载完整相簿。

## 已知限制

- Advanced Data Protection、FIDO 硬件安全密钥及 Apple 登录接口变化受上游库能力影响。
- “全部加载”的耗时与内存占用取决于相簿规模、网络环境和缩略图清晰度。
- 未签名版本可能触发 SmartScreen，后续可通过可信代码签名改善安装体验。
