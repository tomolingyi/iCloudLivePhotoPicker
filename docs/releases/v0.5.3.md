# iCloud Live Photo Picker v0.5.3

首个面向 GitHub 公开发布的 Windows 版本。它提供完整的 PyQt6 桌面界面，可浏览 iCloud 相簿、批量选择照片，并下载原始照片与 Live Photo 配套 MOV。

## 下载

安装版、便携版和整理好的源码包统一通过百度网盘提供：

- 链接：<https://pan.baidu.com/s/13qvegP94vbW2sPKHhcliOg?pwd=r8na>
- 提取码：`r8na`
- 推荐安装版：`iCloudLivePhotoPicker-v0.5.3-Setup.exe`
- 便携版：`iCloudLivePhotoPicker-v0.5.3-windows-x64.zip`

GitHub Release 不附带 Windows 二进制文件，只保留版本标签、版本说明和 GitHub 自动生成的源码快照。

安装版不需要管理员权限。便携版必须完整解压后运行，两个版本都不要求用户另行安装 Python。

## 主要功能

- 邮箱/手机号登录，手机号区号独立输入，新安装默认 `+86 / cn`。
- 相簿、数量、Live Photo 筛选和多种排序方式。
- 虚拟化照片网格、Windows 风格框选、`Ctrl` 追加与边缘自动滚动。
- 可调缩略图与预览清晰度，文件名点击预览，方向键连续浏览。
- Live Photo 照片/MOV 联动选择与 Windows 兼容方向处理。
- 统一的登录、验证码、确认、进度和下载结果界面。
- 本地设置不保存密码或双重认证验证码。

v0.5.3 进一步修复了下载结果弹窗中“打开下载目录”按钮缺少悬停反馈的问题。完整历史记录见 [`CHANGELOG.md`](../../CHANGELOG.md)。
